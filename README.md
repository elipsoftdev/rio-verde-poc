# Río Verde POC

Home comercial estático para presentar los juegos y cuadernos de Río Verde. Mantiene el sitio en modo POC y la directiva `noindex,nofollow,noarchive`.

Los botones de contacto abren WhatsApp con un mensaje preparado para el producto o la consulta elegida. La persona debe revisar y enviar el mensaje dentro de WhatsApp; el sitio no envía mensajes automáticamente.

El carrusel está preparado para sustituir el arte temporal de cada producto por una portada en `assets/products/<slug>.jpg` cuando Río Verde las proporcione. Por ahora solo utiliza los recursos y motivos visuales existentes en el repositorio.
